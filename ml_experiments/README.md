## 2. WSL2 GPU Environment Setup

Training is designed to run in WSL2 (Ubuntu 24.04) leveraging NVIDIA CUDA acceleration on the host RTX 5050 (8 GB VRAM).

```bash
# From workspace root inside WSL2 Ubuntu:
cd ml_experiments
chmod +x setup_env.sh
./setup_env.sh
```

To activate the virtual environment manually:
```bash
source ml_experiments/.venv/bin/activate
```

## 3. Autonomous Dataset Acquisition Cascade

The dataset acquisition module (`src/download_dataset.py`) runs autonomously without human intervention:

1. **Roboflow Source:** Checks for `ROBOFLOW_API_KEY`. If set, downloads the configured comic/manga segmentation project.
2. **Unauthenticated Hugging Face Hub:** If no key is set, pulls open speech-bubble dataset files from Hugging Face Hub into `data/raw/hf/`.
3. **Format Normalization:** Automatically standardizes bounding boxes, polygons, or raw masks into pixel-aligned binary PNGs:
   - `data/processed/real/images/*.png` (RGB, 512x512)
   - `data/processed/real/masks/*.png` (Single-channel 8-bit grayscale: `0` = background, `255` = speech bubble)
4. **Manifest & Checksums:** Generates `data/processed/real/dataset_manifest.json` recording sample count, license metadata, and SHA256 checksums.
5. **Resilient Offline Fallback:** If network mirrors are unavailable, automatically triggers `synthetic_data_gen.py` to populate training data so training never blocks.

### Run dataset acquisition:
```bash
python src/download_dataset.py --count 30
```

## 4. Notebook Workflow Order

Run notebooks sequentially using the `comictypeset-ml` kernel:

1. **`01_dataset_and_mask_visualization.ipynb`**
   - Inspects `dataset_manifest.json`.
   - Validates mask binary values (`0` and `255`) and spatial dimensions.
   - Plots side-by-side inspection grids with alpha-blended overlays.

2. **`02_train_mobilenet_unet.ipynb`**
   - Configures mixed precision (`mixed_float16`) and loads `config.yaml`.
   - Builds MobileNetV2-UNet with Dice + BCE loss.
   - Trains on deterministic 80/10/10 split and exports checkpoint to `backend/models/bubble_unet.keras`.
   - Appends run metrics to `experiment_notes.md`.

3. **`03_end_to_end_pipeline_visual_debug.ipynb`**
   - Visualizes all pipeline stages: Input Page $\to$ Mask Prediction $\to$ Bounding Boxes $\to$ OCR $\to$ Translation $\to$ Inpainting $\to$ Typesetting.
